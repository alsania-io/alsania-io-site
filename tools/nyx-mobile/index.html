What is Nyx Mobile?

Nyx Mobile is the mobile-optimized build of Nyx Control, designed for Firefox Mobile and other mobile browsers that support extensions.

It delivers the same MCP tool integration and AI platform support as the desktop extension, wrapped in a touch-friendly interface built for small screens.

Mobile-Optimized Features

👆 Touch-Friendly UI

44px+ touch targets, slide-out sidebar, and bottom navigation built for thumbs.

🎈 Floating Action Button

Quick access to the sidebar from anywhere on the page.

👋 Swipe to Close

Natural gesture support for opening and dismissing panels.

📐 Safe Area Support

Respects notches and rounded corners on modern phones.

⚙️ Same Powerful Backend

Full MCP support, all AI platform integrations, tool execution, and persistent memory.

🔒 Privacy First

No telemetry. All processing stays local to your device.

Install on Firefox Mobile

  1. Download the .xpi file above.
  2. Open Firefox Mobile and go to about:addons.
  3. Tap the gear icon → "Install Add-on From File".
  4. Select the downloaded .xpi file.

Other supported browsers: Kiwi Browser (Android), Edge Canary (Android). Safari and Chrome Mobile have limited or no extension support.
